# Liga Board (liga-board-fe)

Доски обратной связи.

## Стек

- **Vite + React + TypeScript**
- **TailwindCSS**
- **ESLint (flat config)**, с запретом `any`
- Менеджер состояний **Zustand**

## Архитектура (структура проекта)

- **`src/pages/`**: страницы приложения.
- **`src/components/`**: переиспользуемые компоненты.
  - **`src/components/ui/`**: UI-кит (`Button`, `Input`, `Card`).
  - **`src/components/layout/`**: основные блоки сайта (`Header`, `Frame`, `Footer`).
- **`src/router/`**: конфигурация роутера.

## Маршруты (URL)

Все перечисленные пути относительно корня сайта. Несуществующий путь ведёт на страницу **404** (`NotFound`). Ошибки загрузки/рендера маршрута показываются через **`ErrorPage`** (`errorElement`).

| Путь            | Назначение                  |
| --------------- | --------------------------- |
| `/`             | Страница со всеми комнатами |
| `/login`        | Вход                        |
| `/register`     | Регистрация                 |
| `/board/:id`    | Доска                       |
| `/board/create` | Создание доски              |
| `/board/update` | Редактирование доски        |
| `/rooms/:id`    | Комната                     |
| `/rooms/create` | Создание комнаты            |
| `/rooms/update` | Редактирование комнаты      |
| `/card/:id`     | Карточка                    |
| `/card/create`  | Создать карточку            |
| `/card/update`  | Редактирование карточки     |
| `/no-access`    | Нет доступа                 |
| `*` (остальное) | 404 — страница не найдена   |

## Быстрый старт

Установка зависимостей:

```bash
yarn install
```

Запуск дев-сервера:

```bash
yarn dev
```

Переменные окружения (опционально):

```bash
cp .env.example .env
```

Сборка:

```bash
yarn build
```

Линтер:

```bash
yarn lint
```
