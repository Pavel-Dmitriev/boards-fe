# MVP: Доска обратной связи (аналог yaBoard)

## 1. Цель MVP

Создать рабочий прототип системы сбора обратной связи, который можно быстро развернуть и протестировать. Пользователи могут просматривать доски и карточки, авторизованные — создавать карточки, голосовать, комментировать. Модераторы и администраторы управляют контентом.

---

## 2. Функциональность MVP

### 2.2. Функциональные модули

#### 2.2.1. Аутентификация

- Регистрация (email, имя, пароль)
- Вход по email/паролю
- Выход
- Защищенные маршруты (только для авторизованных)

#### 2.2.2. Доски

- **Список досок:** главная страница со всеми досками
- **Просмотр доски:** карточки с сортировкой и фильтрацией по категориям
- **Создание доски:** только админ и модератор
- **Редактирование/удаление доски:** только админ и модератор

#### 2.2.3. Карточки

- **Поля:** заголовок, описание, категория, статус, автор, дата, счетчики голосов и комментариев
- **Создание:** авторизованный пользователь (выбирает доску и категорию)
- **Редактирование:** автор, модератор, админ
- **Удаление:** автор (если нет комментариев), модератор, админ
- **Изменение статуса:** только модератор и админ
- **Голосование:** пользователь может поставить/снять голос (один раз)
- **Сортировка:** по голосам, по дате (новые/старые), по комментариям, по алфавиту

#### 2.2.4. Комментарии

- **Создание:** авторизованный пользователь под любой карточкой
- **Редактирование:** только автор комментария
- **Удаление:** автор, модератор, админ

#### 2.2.5. Категории

- Привязаны к доске
- **Создание/редактирование/удаление:** только модератор и админ
- При удалении категории карточки получают NULL

## 3. Модель данных (упрощенная)

### Таблицы

**users**

- id (uuid, PK)
- email (string, unique)
- password_hash (string)
- name (string)
- role (enum: admin, moderator, user)
- created_at (timestamp)

**boards**

- id (uuid, PK)
- title (string)
- description (text)
- created_by (uuid, FK → users.id)
- created_at (timestamp)

**categories**

- id (uuid, PK)
- name (string)
- board_id (uuid, FK → boards.id, ON DELETE CASCADE)
- created_at (timestamp)

**cards**

- id (uuid, PK)
- title (string)
- description (text)
- board_id (uuid, FK → boards.id, ON DELETE CASCADE)
- category_id (uuid, FK → categories.id, ON DELETE SET NULL)
- author_id (uuid, FK → users.id, ON DELETE CASCADE)
- status (enum: new, in_progress, completed, rejected, default: new)
- likes_count (int, default: 0) — денормализовано
- comments_count (int, default: 0) — денормализовано
- created_at (timestamp)
- updated_at (timestamp)

**votes**

- user_id (uuid, FK → users.id, ON DELETE CASCADE)
- card_id (uuid, FK → cards.id, ON DELETE CASCADE)
- created_at (timestamp)
- PK: (user_id, card_id)

**comments**

- id (uuid, PK)
- content (text)
- card_id (uuid, FK → cards.id, ON DELETE CASCADE)
- author_id (uuid, FK → users.id, ON DELETE CASCADE)
- created_at (timestamp)
- updated_at (timestamp)

## 6. Основные API-маршруты (без детализации)

| Метод  | Эндпоинт                      | Описание                    | Доступ                                   |
| ------ | ----------------------------- | --------------------------- | ---------------------------------------- |
| POST   | `/auth/register`              | Регистрация                 | public                                   |
| POST   | `/auth/login`                 | Вход                        | public                                   |
| GET    | `/boards`                     | Список досок                | public                                   |
| GET    | `/boards/:id/cards`           | Карточки доски (сортировка) | public                                   |
| POST   | `/boards`                     | Создать доску               | admin, moderator                         |
| PUT    | `/boards/:id`                 | Обновить доску              | admin, moderator                         |
| DELETE | `/boards/:id`                 | Удалить доску               | admin, moderator                         |
| GET    | `/boards/:boardId/categories` | Категории доски             | public                                   |
| POST   | `/boards/:boardId/categories` | Создать категорию           | admin, moderator                         |
| GET    | `/cards/:id`                  | Детали карточки             | public                                   |
| POST   | `/boards/:boardId/cards`      | Создать карточку            | auth                                     |
| PUT    | `/cards/:id`                  | Обновить карточку           | автор, admin, moderator                  |
| DELETE | `/cards/:id`                  | Удалить карточку            | автор (если нет комм.), admin, moderator |
| PATCH  | `/cards/:id/status`           | Изменить статус             | admin, moderator                         |
| POST   | `/cards/:id/vote`             | Поставить/снять голос       | auth                                     |
| GET    | `/cards/:cardId/comments`     | Комментарии                 | public                                   |
| POST   | `/cards/:cardId/comments`     | Добавить комментарий        | auth                                     |
| PUT    | `/comments/:id`               | Обновить комментарий        | автор                                    |
| DELETE | `/comments/:id`               | Удалить комментарий         | автор, admin, moderator                  |
| GET    | `/admin/users`                | Список пользователей        | admin                                    |
| PUT    | `/admin/users/:id/role`       | Изменить роль               | admin                                    |

## 7. Фронтенд (страницы)

| Страница       | Описание                                             | Доступ |
| -------------- | ---------------------------------------------------- | ------ |
| `/`            | Список всех досок                                    | public |
| `/board/:id`   | Доска с карточками, сортировка, фильтр по категориям | public |
| `/card/:id`    | Детальный просмотр карточки с комментариями          | public |
| `/login`       | Вход                                                 | public |
| `/register`    | Регистрация                                          | public |
| `/create-card` | Создание карточки (выбор доски)                      | auth   |
| `/profile`     | Профиль пользователя (мои карточки, настройки)       | auth   |
| `/admin`       | Панель администратора (только админ)                 | admin  |
